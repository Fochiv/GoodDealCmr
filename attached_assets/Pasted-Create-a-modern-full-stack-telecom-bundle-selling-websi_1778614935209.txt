Create a modern full-stack telecom bundle selling website for Cameroon called “Good Deal”.

STACK:
- Frontend: Next.js 15 + React + Tailwind CSS
- Backend: Node.js API routes
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- Payments: Mobile Money integration ready (MTN MoMo + Orange Money)
- Fully responsive mobile-first design
- Dark and light mode
- Clean African fintech UI design

MAIN IDEA:
Users can buy internet bundles for:
- MTN Cameroon
- Orange Cameroun

The homepage must display 2 big telecom cards:
1. MTN Cameroon
2. Orange Cameroun

When user clicks a telecom operator:
Show available bundles with:
- bundle name
- data size
- validity
- price
- buy button

EXAMPLE BUNDLES:
MTN:
- 500 FCFA → 2GB / 7 days
- 1000 FCFA → 6GB / 30 days
- 2000 FCFA → 15GB / 30 days

Orange:
- 500 FCFA → 1.5GB / 7 days
- 1000 FCFA → 5GB / 30 days
- 2000 FCFA → 12GB / 30 days

BUY FLOW:
1. User selects bundle
2. User enters phone number
3. User selects payment method:
   - MTN Mobile Money
   - Orange Money
4. User clicks Pay
5. Create order
6. Redirect to payment page
7. After payment success:
   - mark order as paid
   - show success page
   - generate transaction ID
   - save purchase history
